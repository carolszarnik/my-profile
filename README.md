# 👤 Perfil Pessoal | Carol

Projeto de site pessoal desenvolvido para consolidar aprendizados práticos em **HTML5** e **CSS3**, aplicando conceitos de estruturação, estilização e identidade visual própria.

## 🚀 Sobre o Projeto
O site funciona como um portfólio e cartão de visitas digital com estética *Dark Mode*. Ele apresenta uma breve introdução pessoal (estudante de Análise e Desenvolvimento de Sistemas na Universidade Positivo), meus principais hobbies e botões interativos para navegação rápida entre currículo, projetos e contatos.

## 🛠️ Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do conteúdo e inclusão de mídias.
- **CSS3**: Estilização personalizada, paleta de cores escura com acentos em tom azul-pálido, tipografia estilizada e layout responsivo.

## 🎯 Conceitos Praticados
- **Layout & Estilização**: Criação de foto de perfil circular e botões arredondados com contraste para navegação.
- **Tipografia**: Aplicação e estilização de fontes personalizadas para destacar títulos e textos.
- **Sintaxe & Semântica**: Uso adequado de tags HTML para separação clara entre imagem, apresentação textual e links principais.
- **Identidade Visual**: Construção de um tema dark coeso e alinhado ao meu estilo pessoal.
